# pi-prompt-enhancer

pi でプロンプトを書いている最中に、足りていない情報を footer に教えてくれる拡張。送信する前に気づけるので、聞き返しの往復が減る。

## 何が起きるか

プロンプトを書いて手を止めると、footer に評価が出る。

```
いい感じにして
π タスク依頼 0/100 D · 不足5: 目的・ゴール, 背景・前提, 制約, 出力形式, 完了条件
```

右に並ぶのが足りていない項目。埋めていくとスコアが上がる。

```
CSV のエクスポート処理が読みにくいので直したい。背景は先週の条件分岐が増えたこと。
制約は外部依存を増やさないこと。出力は差分のみ。既存テストが通ることを確認条件にする。
π タスク依頼 100/100 A · 不足なし
```

- **Enter を押す前に出る。** 書いている途中で評価が更新される。
- **文章の種類を自動で判定する。** 質問 / タスク依頼 / 分析 / 創作 / 雑談を見分け、その種類に必要な項目だけをチェックする。
- **プロンプト本文は書き換えない。** 追記も改変もしない。表示は footer だけ。

## モデルにも渡る

評価はあなたにだけ見えるのではない。エージェントにも同じ内容が渡るので、足りない情報を推測で埋めず、質問するか、置いた仮定を明示するようになる。

## インストール

```sh
pi install npm:@hikae/pi-prompt-enhancer
```

試すだけなら:

```sh
pi -e npm:@hikae/pi-prompt-enhancer
```

## セットアップ

[TypeSafe の dashboard](https://console.typesafe.ai/keys) で API キーを発行して、環境変数に入れる。

```sh
export TYPESAFE_API_KEY=...
```

| 環境変数 | 既定値 | 説明 |
| --- | --- | --- |
| `TYPESAFE_API_KEY` | （なし） | 必須 |
| `TYPESAFE_MODEL` | `jev-latest` | 使う jev のモデル / エイリアス |

キーが無いときも、呼び出しに失敗したときも、プロンプトはそのまま通る。止まることはない。理由は footer に出る。

## 何を見ているか

項目は Claude の [prompting best practices](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-prompting-best-practices) をもとにしている。種類ごとに見る項目が違う。

| 種類 | 見ている項目 |
| --- | --- |
| 質問 | 目的・ゴール / 背景・前提 / 試したこと / 用途 |
| タスク依頼 | 目的・ゴール / 背景・前提 / 制約 / 出力形式 / 完了条件 |
| 分析 | 目的・ゴール / 背景・前提 / 対象データ / 評価軸 / 出力形式 |
| 創作 | 目的・ゴール / 背景・前提 / 読み手 / トーン・文体 / 例 |
| 雑談 | （なし） |

スコアは、項目の充足率・明確さ・具体性をまとめて 0〜100 にしたもの。A / B / C / D の4段階で表示する。

## footer の読み方

| 表示 | 意味 |
| --- | --- |
| `π タスク依頼 0/100 D · 不足5: 目的・ゴール, ...` | 評価できた。右に並ぶのが足りていない項目 |
| `π タスク依頼 100/100 A · 不足なし` | 追加すべきものは無い |
| `π TYPESAFE_API_KEY 未設定` | キーが環境に入っていない |
| `π jev 失敗: ...` | 呼び出しに失敗した。プロンプトは素通りする |

## 制約

- **書きかけは必ず「不足」だらけになる。** 「書かれているか」を見ているので、入力の途中は全項目が不足に見える。埋めるにつれてスコアが動くのを眺めるのが使い方。
- **入力が止まるたびに TypeSafe を呼ぶ。** 1回あたり 250〜650ms 程度。書き直しが多いほどリクエストも増える。
- **直近の1メッセージしか見ていない。** 会話の文脈は判定に渡していないので、前のターンで共有済みの項目を「不足」と言うことがある。エージェントは会話を読めるので、既知の情報なら無視する。
- **エージェント実行中は評価しない。** 途中で割り込む修正はすぐ届く必要があるため。
- **日本語の判定は英語より不確か。** jev は英語が主言語で、CJK の精度は落ちる（[Models](https://docs.typesafe.ai/models#language-support)）。
- **footer は1行。** 入るのはラベルまでで、ヒント本文までは出ない。
